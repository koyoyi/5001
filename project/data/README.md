# Data sources

The active project uses BEIR FiQA for retrieval and reranking. See [the source audit](fiqa/source_audit.json).

No full corpus, pretrained model or experiment results were downloaded/generated for the proposal. Query and relevance files were inspected in memory to verify split counts. Keep later corpus downloads under raw/ and caches under cache/; these are excluded from Git.

Earlier Energy Efficiency and ESIF metadata have moved to [the topic archive](../archive/2026-11-07_prior_topics/data/).
